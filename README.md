# E-Commerce Intelligent Insights

## Project Overview
E-Commerce Intelligent Insights is a data analytics project that analyzes e-commerce sales, customer behavior, product performance, and profitability using Python and Power BI.

## Objectives
- Analyze overall sales and profit performance.
- Identify top-performing and low-performing products.
- Compare sales across product categories and regions.
- Analyze monthly sales trends.
- Segment customers based on their spending.
- Build an interactive dashboard to support data-driven decisions.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Power BI
- CSV datasets

## Project Workflow
1. Generated a sample e-commerce dataset containing 3,000 order records.
2. Cleaned and prepared the data using Python and Pandas.
3. Performed exploratory data analysis and created charts using Matplotlib.
4. Built an interactive Power BI dashboard with KPI cards, sales charts, customer segmentation, and category and region filters.

## Key Features
- Sales, profit, order, and customer KPIs.
- Sales analysis by category and region.
- Monthly sales trend analysis.
- Product performance analysis.
- Customer segmentation.
- Interactive dashboard filters.

## Dataset
The project uses a sample dataset created for learning and demonstration purposes. It does not represent actual company sales.

## Project Goal
To demonstrate practical skills in data cleaning, exploratory data analysis, data visualization, dashboard development, and business insight generation.
